# Genre Starters

What you get
- Canvas host with input mapping and mobile controls
- In‑game chat (AI/party) overlays
- Character context for HUD
- Asset loader utilities
- Turn manager + FSM for turn‑based
- Text scene engine for narrative

Starters (AI prompts in `docs/AI_GAME_PROMPTS.md`)
- 2D Platformer (Phaser‑style loop) — tilemap, gravity, jump
- 3D Adventure (Three‑style loop) — orbit camera, GLTF load
- Roguelike (grid) — FOV, turn loop, ASCII/tiles
- Turn‑based tactics — initiative, abilities, effects
- Text adventure — nodes, choices, variables
