# Performance & Security Checklist

핵심 점검 항목(마이그레이션 / 러너 / 템플릿 실행 시)

성능
- 장시간 실행 쿼리(> 5s) 식별 및 인덱스 추천
- 대용량 테이블에 대한 배치/페이징 적용
- 백업/Restore 테스트: pg_restore로 복원 시간 측정

보안
- 시크릿: 최소 권한, GitHub Environment `production`에 보관
- Supabase 서비스 키는 `SERVICE_ROLE`로만 사용 (권한 최소화)
- 런너 샌드박스: 네트워크 아웃바운드 제한, 파일시스템 쓰기 제한
- 로깅: 감사 로그에 민감 데이터(풀 텍스트 시크릿)가 남지 않도록 마스킹

테스트
- 복구 시나리오 검증: 가장 최근 백업에서 복원 성공 확인
- 재현 테스트: 실패한 마이그레이션을 안전하게 롤백
